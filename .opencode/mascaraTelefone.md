Adição de Máscara para visualização do telefone nos cards do ADMIN.

## Fluxo de criação ## 

1. Verificar no código do projeto se existe algum tipo de máscara para deixar o telefone aparecendo como (xx) xxxx-xxxx, se caso não existir criar uma seguindo os mesmos padrões de criação dos outros scripts.
2. Buscar no projeto todos os locais onde existem o visualização do telefone para o admin ou usuário.
3. Adicionar a máscara em todos estes locais aproveitando o mesmo Script para mantermos o código organizado.
4. Solicitar testes para verificar se a máscara está funcionando corretamente.
5. Fazer commit na branch Beta sob minha autorização.
