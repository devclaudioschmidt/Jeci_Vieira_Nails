## Menu ADMIN. ##

Aplicação de mudança de design no menu da ADMIN de cards superiores para menu hamburger lateral.

## FlUXO DE CRIAÇÃO ##

1. Verificar estrutura do menu atual.
2. Criar estrutura de menu lateral tipo hamburguer na lateral direita abrindo para o centro do app.
3. Adicionar todos os antigos links que estavam na estrutura anterior.
4. Remover a antiga estrutura mantendo apenas o menu hamburguer.

## REGRAS DE DESIGN. ##

1. Reutilize os mesmos padrões visuais do app devendo reutilizar ids ou classes existentes.
2. O menu deve abrir para o centro do app.
3. O menu deve fechar automaticamente ao clicar em um link (ex: o link deve ficar com o texto "<Procedimentos" assim que clicado, indicando que ele foi fechado).
4. O botão de fechar o menu deve ter um X e deve estar acima do primeiro link do menu, alinhado à direita.

## TESTES ##

1. Verificar se o menu abre e fecha corretamente.
2. Verificar se todos os links estão funcionando.
3. Verificar se o menu fecha automaticamente ao clicar em um link.
4. Verificar se o botão de fechar o menu está funcionando.
