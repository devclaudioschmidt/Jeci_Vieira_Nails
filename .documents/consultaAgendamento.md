Regras para Ferramenta de Consulta de Agendamentos.

Link na Index para buscar agendamentos.

Abre modal de pesquisa.

1. O cliente deve informar o seu telefone para iniciar a consulta.
2. O sistema deve consultar na coleção de agendamentos do firestore
3. O sistema deve retornar todos os agendamentos do cliente, com data, hora, procedimento e valor.

Botão fechar deve fechar o modal.
